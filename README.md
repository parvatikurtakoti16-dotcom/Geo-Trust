🌐 Geo-Trust

Blockchain-Based Property Management System

Geo-Trust is a decentralized application (dApp) designed to enable secure, transparent, and tamper-proof property ownership and transfer using blockchain technology. By leveraging smart contracts, the system eliminates intermediaries, reduces fraud, and ensures trust in real estate transactions.



📌 Overview

Traditional property management systems often suffer from lack of transparency, data manipulation risks, and dependency on centralized authorities. Geo-Trust addresses these challenges by introducing a blockchain-backed property registry, where each asset is uniquely identified and ownership records are immutable.


✨ Key Capabilities

- Decentralized Ownership Registry
  Maintains immutable property records on blockchain

- Smart Contract Automation
  Ensures secure and rule-based property transactions

- Fraud Prevention
  Eliminates duplicate ownership and unauthorized modifications

- Transparent Transactions
  All activities are verifiable and publicly auditable

- User-Centric Interface
  Simplified interaction through a modern web interface



🧱 System Architecture

Geo-Trust follows a modular architecture:

- Frontend Layer
  Web-based interface for user interaction and visualization

- Blockchain Layer
  Smart contracts deployed on Ethereum-compatible network

- Integration Layer
  Communication between frontend and blockchain using Web3 libraries


🛠️ Technology Stack

Layer| Technologies Used
Frontend| HTML, CSS, JavaScript (Vite-based UI)
Blockchain| Solidity, Hardhat
Integration| Ethers.js
Tools| Node.js, Git, GitHub



⚙️ Getting Started

Prerequisites

- Node.js installed
- Git installed
- Basic knowledge of blockchain (recommended)



Installation

git clone https://github.com/parvatikurtakoti16-dotcom/Geo-Trust.git
cd Geo-Trust



Run Frontend

cd frontend
npm install
npm run dev


Smart Contract Deployment

cd smart_contracts
npm install
npx hardhat compile
npx hardhat run scripts/deploy.js
